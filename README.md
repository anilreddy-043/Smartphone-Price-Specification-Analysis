# 📱 Smartphone Price & Specification Analysis

## 📌 Project Overview

The **Smartphone Price & Specification Analysis** project focuses on analyzing smartphone prices and technical specifications to discover meaningful insights and trends in the smartphone market.

This project uses Python-based data analysis techniques to explore how different smartphone specifications, such as RAM, internal storage, battery capacity, processor, camera, and display features, influence smartphone pricing.

The main objective is to understand smartphone market trends, compare different brands, and identify the specifications that contribute to higher smartphone prices.

## 🎯 Project Objectives

- Analyze smartphone prices across different brands.
- Understand the relationship between smartphone specifications and prices.
- Identify the most expensive and affordable smartphones.
- Compare RAM, storage, battery, and camera specifications.
- Explore brand-wise smartphone pricing trends.
- Identify important features influencing smartphone prices.
- Generate meaningful insights through data visualization.

## ⚙️ Installation & Setup

### Step 1: Clone the Repository

```bash
git clone https://github.com/anilreddy-043/Smartphone-Price-Specification-Analysis.git
```

### Step 2: Navigate to the Project Directory

```bash
cd Smartphone-Price-Specification-Analysis
```

### Step 3: Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

Alternatively:

```bash
pip install -r requirements.txt
```

### Step 4: Launch Jupyter Notebook

```bash
jupyter notebook
```

### Step 5: Run the Analysis

Open the project notebook and execute the cells sequentially to explore the smartphone dataset and generate visualizations.
